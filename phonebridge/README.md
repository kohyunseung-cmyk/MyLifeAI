# 업무 브리핑 연결 · Android companion

기존 MyLifeAI와 다른 패키지(`com.mylifeai.phonebridge`)로 설치하는 작은 연결 앱입니다.
수집 자료는 로컬 비공개 DB에 보관하고 사용자가 시스템 파일 선택기에서 지정한 문서에만 씁니다.
앱 자체에는 인터넷 권한, 웹훅, API 키, OAuth 비밀값이 없습니다. Google Drive 앱이 문서 저장·동기화를 담당합니다.

## 설치 후 연결

1. APK를 설치하고 **업무 브리핑 연결**을 엽니다.
2. **카카오톡·문자 알림 연결**에서 이 앱의 알림 접근을 허용합니다. 다른 앱의 알림도 볼 수 있다는 Android 경고는 시스템 권한 범위이며 구현은 카카오톡·삼성 메시지·Google 메시지만 처리합니다.
3. **문자·통화 기록 권한 허용**을 누릅니다. 거부되거나 설치 프로그램이 제한한 권한은 사용할 수 없습니다. 기본 전화/문자 앱을 변경하거나 제한을 우회하지 않습니다. RCS/MMS 전체는 지원하지 않습니다.
4. **준비된 Drive 전달 파일 선택**을 누르고, 왼쪽 메뉴에서 브리핑에 연결된 Drive 계정을 선택합니다. `업무브리핑_휴대폰_최신.json`을 선택합니다. 앱은 `phone-briefing/v1` 스키마가 있는 문서만 기존 전달 파일로 허용합니다. 새 파일 만들기는 별도의 대체 기능이며 기존 파일을 선택할 수 있으면 사용하지 않습니다.
5. **수집 시작**의 범위 안내를 읽고 시작합니다. **지금 갱신**을 누릅니다. 상단 ‘문서 갱신’ 시각·건수를 확인하고 Drive 앱의 해당 파일 업로드 상태를 확인합니다. 휴대폰 저장소를 선택하면 클라우드 브리핑에 전달되지 않습니다.
6. 음성은 **기기 내 음성 메모 받아쓰기**로 짧게 입력하고 인식 결과를 수정·확인해 저장합니다. 녹음 앱이 제공한 TXT 전사문이나 카카오톡 내보내기 TXT는 파일 가져오기 또는 Android 공유 → 이 앱으로 추가할 수 있습니다.

## 정확한 수집 범위

| 자료 | 지원 | 제외·제약 |
| --- | --- | --- |
| 카카오톡 | 허용 이후 도착해 알림에 표시된 텍스트, 직접 가져온 TXT | 전체 과거 대화 자동 조회, 알림이 없는 대화, 보낸 메시지의 완전한 이력, 사진/첨부 내부 |
| 문자 | 권한이 실제 허용되면 최근 7일 SMS 수신·발신, 알림 대체 수집 | RCS/MMS 본문 전체, 설치 프로그램이 허용하지 않은 제한 권한 |
| 통화 내역 | 최근 7일 상대·방향·시각·통화시간 | 통화 음성·실제 대화 내용·업무 완료 추정 |
| 음성 | 기기 내 받아쓰기 결과, 사용자가 확인한 전사문 | 기존 음성/통화 녹음 자동 전사·상시 녹음 |
| 녹음 원본 연결 | 선택한 파일명과 ‘미전사’ 표시 | 파일 내용 전송·전사. 실제 음성파일 접근권한은 보존하지 않음 |

Android의 기기 내 음성 인식과 한국어 모델이 지원되어야 받아쓰기가 됩니다. 다른 클라우드 인식기로 조용히 전환하지 않습니다.
이 첫 버전은 **기존 녹음 전체 자동 전사·실기기 권한 승인·클라우드 수신 확인까지 완료한 제품이 아닙니다.**

## 전달 동작

- JobScheduler는 약 15분 간격 및 새 알림 후 갱신을 요청합니다. Android 절전·네트워크·제조사 정책에 따라 지연됩니다. 정시 동기화 보장은 없습니다.
- 시스템 문서 제공자의 지속 쓰기 권한을 사용합니다. 제공자에 따라 백그라운드 쓰기·클라우드 업로드가 다를 수 있어 실기기 확인이 필요합니다.
- 성공은 문서 제공자 스트림 쓰기 완료를 뜻합니다. Drive 서버 업로드/브리핑 수신을 확인했다는 뜻이 아닙니다.
- `generatedAt`, `enabled`, `sources`, 각 자료의 `coverage`, 누락·상한 표시를 함께 내보냅니다.
- 수집 중지 시 작업을 취소하고 가능한 경우 전달 문서에 `enabled:false`와 빈 자료를 씁니다. 이미 전달된 문서는 Drive에 남을 수 있습니다.
- 자료는 최근 7일·저장 이벤트 최대 1,000개·본문 총 약 90만 자로 제한됩니다. SMS·통화 별도로 최대 1,000개이며 상한을 표시합니다.
- 알림 중복은 출처·방·발신자·시각·본문 해시로 제거합니다. SMS 알림과 문자함의 같은 내용은 분석 단계에서 추가 병합해야 합니다.
- 인증번호로 보이는 메시지는 제외하지만 자동 필터가 모든 비밀정보를 식별한다고 보장하지 않습니다.
- 브리핑 분석에서 `audio_pending`은 대화내용의 근거가 아닙니다. 가져오기 시각과 원문 대화 날짜를 혼동하지 않습니다.
- 회사 SSO, Apps Script 편집기, Chat 대화방, 수신확인 절차에 접근하지 않습니다.

## 검증

`gradle :phonebridge:testDebugUnitTest :phonebridge:lintDebug :phonebridge:assembleDebug`

단위 테스트: 허용 패키지, 인증번호 제외, 한글 BOM, 중복키, 부재중 통화 구분.
설치·권한 거부·Drive 문서 쓰기·백그라운드 동기화·음성 인식은 실제 휴대폰에서 추가 확인해야 합니다.
공개 저장소에 원본 메시지, 통화 내역, 녹음, 회사 계정 정보, 전달 파일 ID 또는 키를 넣지 않습니다.
